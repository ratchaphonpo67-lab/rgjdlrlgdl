# 💻 CAI วิทยาการคำนวณ ม.1 (ว21103)
**โรงเรียนเตรียมอุดมศึกษาพัฒนาการ**

แอปพลิเคชันบทเรียนคอมพิวเตอร์ช่วยสอน (Computer-Assisted Instruction: CAI) สำหรับรายวิชาวิทยาการคำนวณ (ว21103) สำหรับนักเรียนระดับชั้นมัธยมศึกษาปีที่ 1 ที่โรงเรียนเตรียมอุดมศึกษาพัฒนาการ ออกแบบมาเพื่อเสริมสร้างทักษะการคิดเชิงคำนวณ (Computational Thinking) โดยเฉพาะ **แนวคิดเชิงนามธรรม (Abstraction)** และ **การออกแบบอัลกอริทึม (Algorithm Design)** ผ่านสื่อการเรียนรู้แบบอินเทอร์แอกทีฟและแนวคิดแบบเกมมิฟิเคชัน (Gamification)

---

## 📖 ข้อมูลทั่วไป (Project Overview)
- **รายวิชา:** วิทยาการคำนวณ (ว21103)
- **กลุ่มผู้เรียน:** นักเรียนระดับชั้นมัธยมศึกษาปีที่ 1 (ห้องเรียนพิเศษวิทยาศาสตร์-เทคโนโลยี รองรับนักเรียน 30 คน)
- **สถาบัน:** โรงเรียนเตรียมอุดมศึกษาพัฒนาการ
- **มาตรฐานการเรียนรู้:** สาระที่ 4 เทคโนโลยี มาตรฐาน ว 4.2
- **ตัวชี้วัด:** ว 4.2 ม.1/1 ออกแบบอัลกอริทึมที่ใช้แนวคิดเชิงนามธรรมเพื่อแก้ปัญหาหรืออธิบายการทำงานที่พบในชีวิตจริง

## 🏗️ สมมติฐานการออกแบบและข้อจำกัดของระบบ (Assumptions & Limitations)
เนื่องจากระบบนี้เป็นแอปพลิเคชันที่ทำงานบนฝั่ง Client (Front-end) เพียงไฟล์เดียวเพื่อให้สามารถ Preview และใช้งานได้ทันที จึงได้กำหนดสมมติฐานการทำงานดังนี้:
1. **Mock Backend (Supabase):** ระบบฐานข้อมูลและระบบยืนยันตัวตน (Authentication) ถูกจำลองขึ้นมาแบบ In-memory (`MOCK_STUDENTS` และ `supabaseService`) แทนที่การต่อเชื่อม Supabase จริง
2. **นักเรียน 30 คน:** ระบบได้สุ่มสร้างรายชื่อและรูปโปรไฟล์นักเรียนจำนวน 30 คนให้โดยอัตโนมัติ เพื่อให้ครูสามารถเห็นภาพรวมของระบบ Dashboard ได้ทันที
3. **Storage:** ระบบอัปโหลดไฟล์ใน Teacher Dashboard เป็นเพียง UI สำหรับสาธิต ไม่ได้มีการบันทึกไฟล์ลงเซิร์ฟเวอร์จริง
4. **เนื้อหา (No AR/VR):** ตัดเทคโนโลยี AR, VR หรือ WebAR ออกตามข้อกำหนด เน้นที่ Interactive Web Elements และ Gamification (การลากวาง, การเลือกคำตอบ) แทน

## 🚀 ฟีเจอร์หลัก (Key Features)

### 1. 🎓 ฝั่งนักเรียน (Student Canvas)
- **หน้าเข้าสู่ระบบ:** เลือกชื่อนักเรียนจากรายชื่อ 30 คน (Demo)
- **ระบบสะสมความก้าวหน้า:** แสดงคะแนน (Score) และแถบความก้าวหน้า (Progress Bar)
- **บทเรียนที่ 1 (แนวคิดเชิงนามธรรม):** ภารกิจจำลองสถานการณ์เลือกซื้อโทรศัพท์มือถือ ให้นักเรียนคัดแยกข้อมูลที่ "สำคัญ" และ "ไม่สำคัญ" (Abstraction)
- **บทเรียนที่ 2 (การออกแบบอัลกอริทึม):** ภารกิจต้มบะหมี่กึ่งสำเร็จรูป ให้นักเรียนนำข้อมูลมาจัดเรียงลำดับขั้นตอน (Algorithm) ให้ถูกต้อง

### 2. 👨‍🏫 ฝั่งครูผู้สอน (Teacher Dashboard - Supabase Admin)
- **ตารางสรุปผลการเรียน (Progress Tracking):** ดูความก้าวหน้า, คะแนนรวม, และเวลาเข้าใช้งานล่าสุดของนักเรียนทั้ง 30 คน แบบ Real-time
- **ระบบจัดการสื่อ (Media Storage):** จำลองการทำงานของการอัปโหลดไฟล์สื่อการสอนและใบงานขึ้น Supabase Storage

## 📊 เกณฑ์การประเมินผล (Rubric Score)
เกณฑ์การประเมินผลสำหรับตัวชี้วัด **ว 4.2 ม.1/1** (คะแนนเต็ม 4 ระดับ) นำมาประยุกต์ใช้กับผลลัพธ์ในระบบ Dashboard:

| ระดับคะแนน | สมรรถนะการใช้แนวคิดเชิงนามธรรม (Abstraction) | สมรรถนะการออกแบบอัลกอริทึม (Algorithm) |
| :--- | :--- | :--- |
| **ระดับ 4 (ดีมาก)** | แยกแยะข้อมูลที่สำคัญและไม่สำคัญออกจากสถานการณ์ได้อย่างถูกต้องสมบูรณ์ 100% | เรียงลำดับขั้นตอนการแก้ปัญหาได้อย่างถูกต้อง ชัดเจน และมีประสิทธิภาพ |
| **ระดับ 3 (ดี)** | แยกแยะข้อมูลสำคัญได้ถูกต้องส่วนใหญ่ มีข้อผิดพลาดเล็กน้อย (80%) | เรียงลำดับขั้นตอนได้ถูกต้อง แต่กะทัดรัดหรืออาจมีสลับขั้นตอนที่ยอมรับได้ |
| **ระดับ 2 (พอใช้)** | แยกแยะข้อมูลสำคัญและไม่สำคัญได้บางส่วน ต้องอาศัยการชี้แนะ | ลำดับขั้นตอนการแก้ปัญหายังมีความสับสน ข้ามขั้นตอนที่สำคัญ |
| **ระดับ 1 (ปรับปรุง)** | ไม่สามารถคัดแยกข้อมูลที่จำเป็นต่อการแก้ปัญหาได้เลย | ไม่สามารถเรียงลำดับขั้นตอนการแก้ปัญหาได้ หรือทำแล้วไม่เกิดผลลัพธ์ |

> **หมายเหตุ:** ในระบบ CAI หากนักเรียนทำภารกิจผ่าน จะถือว่าอยู่ในเกณฑ์ "ดีมาก" ทันที ระบบถูกออกแบบให้ทดลองทำซ้ำได้จนกว่าจะถูกต้อง (Mastery Learning)

## 💻 Stack เทคโนโลยี (Tech Stack)
- **Core:** React 18
- **Styling:** Tailwind CSS (ผ่าน CDN ใน Environment ปัจจุบัน)
- **Icons:** `lucide-react`
- **Data Layer:** In-memory Javascript Arrays & Promises (จำลอง Supabase)
